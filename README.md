# IncomeFlow Pro - Professional Income Manager 💰

A Progressive Web App (PWA) for tracking salary, allowances, taxes, and generating reports. Designed with iOS-style UI and Japanese Yen currency support.

## Features

- 📅 **Year & Month Selection** - Track income across different years and months
- 🏢 **Editable Companies** - Add, edit, or delete company names
- 💰 **Income Tracking** - Record Net Salary, Allowances, and Income Tax
- 📊 **Worked Income Calculation** - Automatically calculates Net Salary minus Allowances
- 📋 **Reports** - Generate reports by date range and company filter
- 📎 **Export Options** - Download reports as CSV or JSON
- 🗑️ **Reset Data** - Clear all data with confirmation modal
- 📱 **PWA Support** - Install on iOS/Android devices as a native app
- 💾 **Local Storage** - All data saved locally on your device

## Installation
